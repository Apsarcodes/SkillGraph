# SkillGraph AI — Industry & Curriculum Competency Mapping

This document provides a detailed mapping between SkillGraph AI's architectural implementation and industry-standard engineering competencies (including Wipro TalentNext / Enterprise Full-Stack & AI tracks).

| Competency Track / Module | Specific Industry Requirement | SkillGraph AI Implementation & Evidence | Verification Test Suite |
| :--- | :--- | :--- | :--- |
| **Module 1: Core Programming, OOP & Data Structures** | - Strong Python 3.9+ OOP & Pydantic Data Models<br>- Directed Acyclic Graph (DAG) structures<br>- Cycle detection and Topological Sorting | - `backend/core/graph.py` implements DFS topological sort with cycle detection.<br>- Pydantic v2 schemas in `backend/schemas/`. | `test_graph_topological_sort`<br>`test_cycle_resolution` |
| **Module 2: Modern Full-Stack Development** | - Responsive SPA with React, TypeScript & Tailwind<br>- RESTful API services with FastAPI<br>- Interactive Node-Edge Graph Visualizer | - Vite React UI with `@xyflow/react` in `frontend/src/`.<br>- Complete CRUD endpoints in `backend/routers/`. | `test_api_endpoints`<br>`npm run build` |
